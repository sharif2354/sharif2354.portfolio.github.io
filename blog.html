Dynamic ICU Mortality Prediction with Transformers on MIMIC-IV

My undergraduate thesis investigates predicting dynamic in-hospital mortality for intensive care unit patients using Transformer-based sequence architectures. Clinical physiological streams are inherently irregular, multi-rate, and characterized by sporadic observation intervals.

Key Architectural Challenges

  • Irregular Time-Series Alignment: Processing longitudinal electronic health records without discarding temporal spacing between consecutive clinical tests.
  • Multi-Head Self-Attention: Modeling complex interactions across physiological metrics (vital signs, lab biomarkers, vasoactive drug infusions) over variable observation windows.
  • Dynamic Risk Horizon Forecasting: Producing rolling 24-hour and 48-hour mortality probability distributions rather than static single-instance labels.

By leveraging PhysioNet's MIMIC-IV database, the objective is to generate calibrated, actionable predictions early enough during a patient's stay to support acute clinical interventions.

COMPUTER VISION • AUDIO PROCESSING • MULTIMODAL AI

Multimodal Lie Detection Using Late Fusion and Temporal Attention

Human deception exhibits subtle, distributed indicators across multiple sensory streams. This project introduces a deep learning framework combining acoustic representations with facial visual dynamics, benchmarked on the DOLOS dataset to reach 82% classification accuracy[cite: 20].

System Pipeline

  • Visual Feature Extractor: Processing temporal facial micro-expressions and head pose variations over frame sequences.
  • Acoustic Signal Processing: Extracting spectrogram representations to isolate pitch instability, pause rates, and harmonic irregularities.
  • Late Fusion Layer: Concatenating high-level modality embeddings with cross-attention to preserve unimodal signal integrity prior to the final decision boundary.
FULL-STACK • DJANGO REST • PYTORCH INFERENCE

Architecting SmartCart-AI: Computer Vision in Modern E-Commerce

SmartCart-AI bridges modern web engineering with real-time visual product identification. The architecture utilizes Django REST Framework and PostgreSQL for transactional state, coupled with a PyTorch ResNet-50 inference pipeline for image-based product discovery.

Implementation Breakdown

  • Optimized multi-part image ingestion with authenticated token management.
  • Asynchronous background model inference to prevent blocking server threads.
  • PostgreSQL relational indexing for low-latency product catalog queries.
  • Responsive client interface with CSS Grid and modular React component states[cite: 9].

Declarative Data Visualization in Plain CSS

Building data-dense interfaces—such as schedule matrix heatmaps and responsive editorial gazettes—does not always demand heavy client-side JavaScript libraries[cite: 9]. By using CSS attribute substring selectors ([class*="available-"]) and hard-line linear gradients, tabular layouts can map status data into visual heatmaps natively while preserving strict accessibility via ARIA attributes[cite: 9].

CSS Grid Architecture

CSS Grid provides two-dimensional layout mechanisms combining explicit columns and automatic row sizing.

grid-template-areas: "title title title" "feature-article feature-article cover-image";
  • Fractional units scale fluidly across viewports without rounding errors.
  • Subgrids allow nested children to align cleanly with ancestor tracks.
  • Gap declarations eliminate the need for fragile margin hacks on items.

Attribute Selectors

Attribute selectors target elements based on the exact presence or substring structure of their attributes.

tr[class="read"] span[class="status"] { border: 1px solid #22c55e; }
  • The ^= operator matches attribute strings beginning with a specific prefix.
  • The ~= operator matches distinct whitespace-separated words within class strings.

Keyframe Animations

CSS keyframe animations enable hardware-accelerated transitions along translation and rotation vectors.

@keyframes orbit { 0% { transform: rotate(0deg); } 100% { transform: rotate(360deg); } }

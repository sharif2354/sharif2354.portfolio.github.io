Introduction

JavaScript is a lightweight, cross-platform, object-based scripting language primarily used to bring interactivity to web pages.

Inside a host environment like a web browser, JavaScript can be connected to the objects of its environment to provide programmatic control over them.

console.log("Welcome to JavaScript Documentation");
JavaScript Basics

JavaScript borrows most of its syntax from Java, C, and C++, but has also been influenced by Awk, Perl, and Python.

JavaScript is case-sensitive and uses the Unicode character set. You can write statements followed by an optional semicolon.

const greeting = "Hello, world!";
Variables and Types

You use variables as symbolic names for values in your application. The names of variables, called identifiers, conform to certain rules.

You can declare a variable in three ways using specific keywords depending on scoping needs:

  • var declares a function-scoped or globally-scoped variable.
  • let declares a block-scoped local variable.
  • const declares a block-scoped, read-only named constant.
  • Numbers represent both integer and floating-point values.
  • Strings represent textual data enclosed within quotes.
let userScore = 100;
Functions and Scope

Functions are one of the fundamental building blocks in JavaScript. A function is a reusable JavaScript procedure—a set of statements that performs a task or calculates a value.

To use a function, you must define it somewhere in the scope from which you wish to call it.

function square(number) { return number * number; }
Modern ES6 Features

ECMAScript 2015 (ES6) introduced significant updates to the language, including template literals, destructuring assignment, default parameters, and classes.

Arrow functions provide a more concise syntax for writing function expressions and lexically bind the this value.

const add = (a, b) => a + b;
